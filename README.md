# Portfolio Andrea Alberici

Sito statico (HTML, CSS, JS), pronto per GitHub Pages. Nessuna build necessaria.

## Struttura
```
index.html
css/style.css        (palette nelle variabili :root in cima)
js/main.js           (testi EN/IT e lista progetti)
assets/
  img/about/personal-foto.png
  img/projects/*.png|jpg
  img/projects/other-projects/*
  downloads/*.pdf    (presentazioni + Andrea-Alberici-CV.pdf)
```

## Cosa aggiungere
Copia dal vecchio repo la cartella `assets/` mantenendo gli stessi nomi dei file, poi aggiungi il CV come
`assets/downloads/Andrea-Alberici-CV.pdf`. Le immagini mancanti restano nascoste e non rompono il layout.

## Deploy
1. Carica tutto nel repo (per il dominio `albe2004.github.io` il repo si chiama `albe2004.github.io`).
2. Settings > Pages > Deploy from a branch > `main` / root.
3. Il sito e' online in un minuto.
